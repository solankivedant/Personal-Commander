WHY LOCAL-FIRST

Everything a munshi handles stays with the munshi.

Files, email, and Office documents aren't things you hand to a stranger. Munshiji runs entirely on this laptop - no cloud, no account, by default.

WHAT IT CONTROLS

Eight tool packs, one voice.

Every tool follows the same rule: what it can touch, whether it asks first, and how to undo it.

HOW IT DECIDES

A cascade, not a chatbot loop.

Most assistants send every request to a language model and wait. Munshiji tries the fast, free paths first - a bigger model only steps in when it truly has to.

Grammar

Deterministic YAML templates. Under 10ms, zero RAM.
