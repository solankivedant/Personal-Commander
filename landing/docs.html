Docs

There's no hosted product yet - so the docs are how to build it.

Munshiji doesn't have an account system or a hosted app to document yet. What exists is a real, runnable codebase - these are the actual docs that ship inside it, not a separate marketing rewrite of them.

01 - RUN IT LOCALLY

Get the voice loop running on your own machine.

Windows 10/11, Python 3.11+, and uv for dependency management. The full voice loop (wake word, Whisper, Kokoro TTS) runs today; routing and tool execution are landing phase by phase - see the roadmap for exactly what that means.

git clone https://github.com/solankivedant/Personal-Commander
cd Personal-Commander
uv sync
uv run python -m munshiji
